## Features

| Feature                     | Description                                                                                                            |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Ship in minutes             | Set a URL, name, and icon to export installers — no need to build a native app from scratch                            |
| One project, many platforms | Target Android, iOS, Windows, and macOS from the same project; export only what you need                               |
| Phone and desktop           | Quickly try Android packaging on your phone; manage projects and multi-platform exports on desktop                     |
| A real app entry            | Users open your site from a home-screen or desktop icon with your branding — more like a product, less like a bookmark |

### Get started in three steps

1. Enter the URL and app details
2. Choose the platforms you need
3. Export, install, or distribute

## Supported platforms

Android · iOS · Windows · macOS

## Who it’s for

-   Operators and indie developers who want an app-style entry for a website
-   Small teams that need lightweight delivery and fast installers
-   Creators who want the same content on multiple platforms
