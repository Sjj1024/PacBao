## 功能介绍

| 能力               | 说明                                                          |
| ------------------ | ------------------------------------------------------------- |
| 几分钟出包         | 填网址、定名称、选图标，即可导出安装包，无需从零开发原生应用  |
| 一次配置，多端可用 | 同一项目面向 Android、iOS、Windows、macOS，按需导出你要的平台 |
| 手机与桌面都可用   | 手机上快速试用；桌面端管理项目并导出多平台                    |
| 独立 App 体验      | 自定义名称与图标，从桌面图标打开你的站点，更像正式产品入口    |

### 三步上手

1. 填写网址与应用信息
2. 选择目标平台
3. 导出并安装 / 分发

## 支持平台

Android · iOS · Windows · macOS

## 适合谁

-   希望给网站做一个独立 App 入口的运营与独立开发者
-   需要轻量交付、快速出安装包的小团队
-   同一内容要覆盖多个平台的创作者
