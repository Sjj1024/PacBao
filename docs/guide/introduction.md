# 产品介绍

**PacBao** 帮你把网站变成可安装的多端应用：填写网址、应用名称和可选图标，即可导出手机或桌面端安装包，让用户从独立图标打开你的站点。

## 它能做什么

很多业务只需要一个「打开某个网页」的独立入口，却不想单独做一整套原生 App。PacBao 把这件事简化为：

1. 填写网址与应用信息  
2. 选择目标平台  
3. 导出并安装 / 分发  

适合独立站、活动页、后台入口、轻量 SaaS 前台等场景。

## 你能得到什么

| 价值 | 说明 |
|------|------|
| 更快上线 | 不必从零开发原生壳应用 |
| 多端覆盖 | 同一项目导出 Android、iOS、Windows、macOS 等 |
| 品牌入口 | 自定义名称与图标，用户感知更清晰 |
| 灵活试用 | 手机快速打 Android 包；桌面做项目管理与多端导出 |

## 适合谁

- 希望给网站做一个独立 App 入口的运营与独立开发者  
- 需要轻量交付、快速出安装包的小团队  
- 同一内容要覆盖多个平台的创作者  

## 使用边界

- 适合以 **在线网址** 为内容主体的应用入口  
- 侧重快速试用、侧载与内部分发；商店上架流程需自行完成  
- 不替代完整原生产品研发（复杂原生能力、深度系统集成等）
