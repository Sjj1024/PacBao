# 快速开始

按场景选择入口：手机上快速打 Android 包，或在桌面端管理项目并导出多平台。

## 方式一：手机打包（Android）

1. 安装 PacBao 打包器 App  
2. 填写 **网站地址**、**软件名称**，可选自定义图标  
3. 点击开始打包  
4. 安装生成的应用，从桌面图标打开你的网站  

适合先验证效果、给同事或客户快速试用。

## 方式二：桌面打包（多平台）

1. 打开桌面版 PacBao  
2. 创建项目，填写应用名与网址  
3. 设置图标与各平台选项  
4. 选择目标平台并导出安装包  

适合需要同时产出多个平台、长期管理多个项目的场景。

## 使用前小提示

- 网址请使用可正常访问的 https / http 地址  
- 应用名称会显示在桌面与系统设置中，建议简短好认  
- 图标建议使用清晰的正方形图片，便于各平台展示
