# 多端支持

PacBao 面向「同一项目、多端应用入口」。你配置一次，再按需导出各平台安装包。

## 平台一览

| 平台 | 你能得到什么 | 适合场景 |
|------|--------------|----------|
| **Android** | 可安装的 Android 应用 | 手机试用、侧载分发、内测 |
| **iOS** | iOS 安装包 | 企业分发或自行完成签名后安装 |
| **Windows** | Windows 可运行包 | 桌面入口、内网工具、客户演示 |
| **macOS** | macOS 应用或轻量入口 | Mac 用户桌面入口 |

> 各平台能力会持续完善；具体可导出项以当前产品界面为准。

## 怎么选

- **只想先看效果** → 用手机打一个 Android 包最快  
- **要同时给 Windows / Mac 用户** → 用桌面端按平台分别导出  
- **要长期维护多个站点入口** → 在桌面端用项目管理统一配置  

## 分发说明

- 适合快速试用、团队内测与内部分发  
- 若需上架应用商店，请自行完成各平台的账号、审核与合规要求  
- PacBao 帮你把网站变成独立入口，商店上架流程不在产品默认范围内  

了解使用步骤请看 [快速开始](./getting-started)。
