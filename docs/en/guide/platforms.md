# Platforms

PacBao is built for **one project, multi-platform app entries**. Configure once, then export installers for the platforms you need.

## Overview

| Platform | What you get | Best for |
|----------|--------------|----------|
| **Android** | Installable Android app | Phone trials, sideload, internal testing |
| **iOS** | iOS package | Enterprise distribution or install after you handle signing |
| **Windows** | Runnable Windows package | Desktop entry, internal tools, client demos |
| **macOS** | macOS app or lightweight entry | Desktop entry for Mac users |

> Platform coverage keeps evolving; see the current product UI for what you can export today.

## How to choose

- **Just want to try it** → Pack an Android app on your phone  
- **Need Windows / Mac users covered** → Export each platform from desktop  
- **Managing many site entries** → Keep projects and config in the desktop app  

## Distribution notes

- Great for trials, internal testing, and private distribution  
- For public stores, complete each platform’s account, review, and compliance yourself  
- PacBao turns a website into a dedicated entry; store submission is outside the default product scope  

See [Get started](./getting-started) for the steps.
