# Get started

Choose your path: pack an Android app on your phone, or manage projects and multi-platform exports on desktop.

## Option 1: Pack on phone (Android)

1. Install the PacBao packager app  
2. Enter the **website URL** and **app name**; optionally pick an icon  
3. Start packing  
4. Install the generated app and open your site from the home-screen icon  

Best for a quick trial with teammates or clients.

## Option 2: Pack on desktop (multi-platform)

1. Open PacBao desktop  
2. Create a project; set app name and URL  
3. Configure icon and per-platform options  
4. Choose a target platform and export  

Best when you need multiple platforms or manage several projects over time.

## Quick tips

- Use a publicly reachable https / http URL  
- Keep the app name short and recognizable on the home screen  
- Prefer a clear square icon for consistent display across platforms
